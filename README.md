## Overview

This repository contains the official implementation for my **Bachelor's Thesis in Computer Science**.

The project investigates **Quantum Extreme Learning Machines (QELM)** applied to computer vision. It implements a hybrid architecture combining **Deep Learning** (Convolutional Autoencoders) for dimensionality reduction with **Quantum Reservoir Computing** for non-linear feature mapping.

The goal is to demonstrate that a quantum-enhanced pipeline can achieve competitive accuracy on the **MNIST dataset** while utilizing a fraction of the trainable parameters required by classical deep networks.

## The Architecture

The pipeline addresses the "NISQ bottleneck" (limited qubits) through a 4-step process:

1.  **Dimensionality Reduction:** A **Convolutional Autoencoder (CAE)** compresses $28 \times 28$ images into a compact latent vector (e.g., $N=4$ or $8$ features).
2.  **Quantum Encoding:** Latent features are mapped to a quantum state via **Dense Angle Encoding**.
3.  **Reservoir Evolution:** The encoded state passes through a fixed, untrained quantum reservoir (5 layers of a CNOT ring followed by random RY rotations), simulated with a custom statevector simulator; entanglement projects the data into a higher-dimensional Hilbert space and the measurement probabilities are used as features.
4.  **Readout:** A classical linear layer (Ridge Regression) is trained on the quantum measurements.

## Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Gabriele8967/QELM_Thesis.git
   cd QELM_Thesis
   ```
2. **Install dependencies** (a virtual environment is recommended):
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

## Configuration and Usage

1. **Configure the Experiment**

   Open ```configs/config.yaml``` to adjust parameters:

      ```yaml
      experiment:
        seed: 42
        device: "cpu"     # "auto", "cpu" or "cuda"
      model:
        latent_dim: 20    # autoencoder features; the QELM uses latent_dim / 2 qubits
      training:
        epochs: 10
        lr: 0.001
      ```
2. **Run the Training**
   To download the dataset and train the Autoencoder (Phase 1), simply run:

      ```Bash
      python main.py
      ```
      The script will:

      1. Load the config.

      2. Set the random seed (for reproducibility).

      3. Train the model.

      4. Save the weights to `data/checkpoints/ae_mnist.pth`.

3. **Train the QELM readout**
   With the autoencoder weights in place, run from the repository root:

      ```bash
      python src/training/train_qelm.py
      ```
   It extracts the quantum reservoir features for the training set, solves the regularised least-squares readout in closed form and prints the test accuracy.

4. **Analyses** (optional): the scripts in `src/analysis/` reproduce the baseline comparison, clustering, t-SNE, entanglement and phase-transition plots saved in `results/`.

MNIST is downloaded automatically on first run and is not stored in the repository.


## Methodology & References
The theoretical framework follows the QELM setup proposed by the Quantum Computing Group at the University of Calabria (Unical).

In the 2025 reference paper the reservoir dynamics is generated by a **Transverse Field Ising Model (TFIM)** Hamiltonian. In this repository the reservoir used by the main pipeline (`src/quantum/custom_layer.py`) is implemented as a fixed random quantum circuit instead; `src/analysis/analyze_phase_transition.py` and `analyze_entanglement.py` measure the per-qubit entanglement entropy of the reservoir and how the results change with the number of reservoir layers.
